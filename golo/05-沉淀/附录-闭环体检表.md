本表用于一次现场自查，或对一份既有 SOP 做结构体检。十二项分四组，每组三项，对应闭环的四处接缝：**看得见、改得动、留得下、算得清。**

填写规则：每项只写三种结果之一——**是/否/部分**；凡填"是"，必须在最后一栏写出具体的表名、单据号或文档章节，写不出位置视同"否"。全部十二项跑完，任何一组出现两个及以上"否"，该组对应的回流路径即视为断开。

| 接缝 | 检查项与判断依据 | 结果（是／否／部分） | 证据位置（表名／章节／页面） |
|---|---|---|---|
| 看得见 | 每条素材有唯一标识，且标识在同一系统内不重复 |  | |
| 看得见 | 由素材标识可查到它所属的款号与主打卖点 |  | |
| 看得见 | 由素材标识可查到实际投放它的计划、消耗与成交结果 |  | |
| 改得动 | 每次复盘的输入是固定的数据表，而非临时取数 |  | |
| 改得动 | 复盘结论落成"保留／调整／停止"三类动作之一 |  | |
| 改得动 | 结论写明改哪个输入、谁执行、什么时候回看 |  | |
| 留得下 | 有可复用资源库（镜头、达人、模板），且标注使用条件 |  | |
| 留得下 | 有内容模型记录：人群、卖点、场景、表达的组合与适用范围 |  | |
| 留得下 | 有正反案例，保留效果数据与复盘结论，不只留成片 |  | |
| 算得清 | 同一条链上同时看得到制作成本、投放消耗与成交 |  | |
| 算得清 | 指标使用可比口径，未把相关性直接写成因果 |  | |
| 算得清 | 目标值与实际值分栏记录，未实现的收益不写成成果 |  | |

#### 结果怎么用

**十二项全"是"**：环是通的，重点转向缩短单轮周期，也就是提高转速。

**第一组有"否"**：先补数据关联，不要先开复盘会。此时任何归因都缺少证据，会议开得越勤，分歧越大。

**第二组有"否"**：复盘在产出报告而不产出决策。检查项落在会议输入表与结论登记格式上，与工具无关。

**第三组有"否"**：每一轮都在重新交学费。沉淀的定义是"下一轮能直接调用"，入库不等于沉淀。

**第四组有"否"**：内容侧与投放侧各报一套数，闭环在纸面上存在，在账面上不存在。

> 本表只提供检查口径，不含目标值与承诺比例。具体阈值需按账号与品类试跑后商定；跨品牌、跨账号的经验数值不得直接沿用。
