# 高乐捷内容复盘会 · 五段式模板 v1.0

> 适用范围：单 SPU 周度复盘会 · 60 分钟 · 首月试运行
> 编制：FDE 马亚鹏 · 2026-10-10
> 设计原则：所有结论必须落到「具体画面/具体文案/具体人群」；所有推断必须配一个下周可执行、可验证的动作。

---

## 一、会议基本设置

| 项目 | 设定 | 说明 |
|------|------|------|
| 频率 | 每周 1 次，固定时间 | 建议周一上午或周五下午，与投放周节拍对齐 |
| 时长 | 60 分钟，各段时间盒硬约束 | 超时话题转入台账跟踪，不现场展开 |
| 范围 | 首月只看 1 个核心 SPU | 跑顺后再扩多 SPU / 多小组轮转 |
| 参会人 | 主持（FDE 兼）+ 内容编导 + 投放运营 +（可选）摄影 | 首月由 FDE 主持示范，第 5 周起移交指定牵头人 |
| 会前截止 | 会议前一天 18:00 | 台账 A 全部标记完成、数据门户导出素材效果榜，否则会议改期 |

### 会前准备清单（责任人：牵头人）
1. 从数据门户导出本 SPU 本周素材效果榜（按消耗/ROI 排序）；
2. 台账 A（测试标记台账）全部测试素材更新状态；
3. 挑出 3~5 条待看片素材：跑量最好的 1~2 条 + 反差最大的 1 条（高曝光低转化或低曝光高转化）+ 本周主推测试方向 1 条；
4. 打开台账 B（结论-验证台账），核对上周验证项是否到期。

---

## 二、五段式流程

### 段 1：目标 vs 实际（5 分钟）

- 汇报本周消耗目标 vs 实际、达成率、素材产量目标 vs 实际、开播/上线天数。
- 一句话给结论：完成 / 未完成 / 未完成的主因初判（一个，不摊开）。
- **规则**：未完成不追究态度，只追究归因是否在段 4 展开。

### 段 2：素材盘点（10 分钟）

按三档过一遍素材池，只报名字和档位，不看片：

| 档位 | 判定口径 | 本周动作方向 |
|------|----------|--------------|
| 跑量（一梯队） | 消耗/ROI 达标且持续 | 维持 + 复刻/混剪承接 |
| 衰退 | 曾达标，本周曲线下滑 | 混剪老带新承接，或明确放弃 |
| 测试中 | 上线不足判定周期 | 待数据，不提前下结论 |

- 同步说明本周内容方向占比（各卖点方向条数/占比），暴露结构问题（如单一卖点占比 >50%）。

### 段 3：逐条看片 · 高光帧定位（20 分钟，核心环节）

- 每条素材播放一遍，对照点击/转化曲线，定位**高光帧（峰值点）落在哪个画面、讲哪个卖点**。
- 全员轮询一句观感，颗粒度要求到：开头钩子、画面冲击力、出镜人（显老/显幼/人群匹配）、运镜、调色、BGM 节奏、穿搭是否呈现卖点（如曲线是否被包住）、卖点细节是否拍到位（如 U 型领是否露边）。
- **两条硬规则**：
  1. 评论区必须看过：「评论区在顾虑什么」要进段 4 的素材问题清单（顾虑点 = 下一条素材要植入的消除点）；
  2. 高光帧是市场需求的证据：高光帧落在 X 卖点 → 记录「市场对 X 有需求」，进台账 B 待放大验证。

### 段 4：归因（15 分钟）

对段 2、段 3 暴露的每个问题，逐一归因，**必须落到四要素之一**：

| 归因维度 | 追问话术 | 示例 |
|----------|----------|------|
| 需求 | 「用户凭什么要这个？痛点是什么？」 | 点击高但转化低 → 只讲了好奇心，没讲解决的痛 |
| 情绪 | 「观众看完有什么感觉？」 | 信息对但画面平 → 缺焦虑/缺向往 |
| 理由（卖点） | 「支撑点来源于哪里？」 | 达人 ROI 高 → 信息密度高，多卖点连贯支撑 |
| 证据 | 「凭什么信？」 | 转化低 → 无实测对比画面 |
| 人群 | 「这条是拍给谁看的？他们和实际转化人群一致吗？」 | 开头画面偏老/偏幼导致人群偏移 |
| 供给侧 | 「预算/资源/时间够不够测？」 | 素材好但跑不出量 → 测试预算仅 30%，结构性问题 |

- **口头禅**：「你的支撑点来源于哪里？」「结论是什么？」「如果南墙碰了，就掉个头。」
- **规则**：归因不了的问题不硬猜，记录为「待归因」，指定归因路径（如：拉人群对比数据、和运营对一次数据、拉竞品同款素材对比）。

### 段 5：下周验证动作（10 分钟）

- 每条段 4 的结论，登记进台账 B：验证动作 + 负责人 + 截止时间。
- **目标算法（首月）**：下周消耗目标 = 本周实际消耗 × 110%（不拍脑袋）。
- **南墙规则**：同一素材形式/同一卖点翻拍 ≥3 次仍无数据，强制触发检讨——「什么东西支撑着你继续下去？」，结论只能是换形式、换人群或暂停。
- 会议结束前过一遍上周台账 B 到期项，未闭环的当场给新截止时间，连续两次延期升级到 FDE。

## 三、台账 A：测试标记台账（字段设计）

> 用途：所有上线测试的素材必须先登记后投放；未标记 = 复盘跟不到单条结果 = 白测。
> 责任人：素材上线当天由投放运营登记；牵头人每周会前核对。

| # | 字段 | 类型/取值 | 填写说明 |
|---|------|-----------|----------|
| 1 | 素材ID | 文本 | 数据门户素材编号，唯一主键 |
| 2 | 素材名称/链接 | 文本 | 便于一键打开 |
| 3 | SPU | 文本 | 关联主 SPU |
| 4 | 素材类型 | 下拉：原创实拍/翻拍/混剪/AI/达人/图文 | |
| 5 | 测试假设 | 文本（一句话） | 必填核心字段：「验证 XXX 能否带来 XXX」，如「收腹卖点放开头3秒能否提高点击」 |
| 6 | 主卖点标签 | 下拉（卖点库） | 与素材库标签体系一致 |
| 7 | 目标人群标签 | 下拉（人群标签） | 如：久坐大胸/微胖/产后 |
| 8 | 创作责任人 | 文本 | |
| 9 | 发布账号 | 文本 | |
| 10 | 投放计划ID | 文本 | 关联千川计划 |
| 11 | 上线日期 | 日期 | |
| 12 | 状态 | 下拉：测试中/已出数据/已判定 | 会前必须更新 |
| 13 | 消耗(元) | 数字 | 数据门户自动同步 |
| 14 | 曝光 | 数字 | |
| 15 | 点击率% | 数字 | |
| 16 | 转化率% | 数字 | |
| 17 | ROI | 数字 | |
| 18 | 高光帧位置/内容 | 文本 | 如「第4秒·收腹画面」，段 3 看片后补 |
| 19 | 结论 | 下拉：验证成功/验证失败/数据不足 | 判定标准由牵头人统一把握 |
| 20 | 评论区反馈摘要 | 文本 | 用户顾虑点原话，如「会卷边」 |
| 21 | 备注 | 文本 | |

**填写红线**：① 状态停在「测试中」超过判定周期（建议 3~5 天或消耗阈值）未更新，会上点名；② 结论列不允许空着关行——数据不足也要写明差多少。

## 四、台账 B：结论-验证台账（字段设计）

> 用途：复盘会的推断闭环器。每条归因结论都必须在这里走完「提出→验证→处置」全程，杜绝「观点上周就提了，这周还没数据反馈」。
> 责任人：牵头人会上登记；FDE 抽查闭环率。

| # | 字段 | 类型/取值 | 填写说明 |
|---|------|-----------|----------|
| 1 | 结论编号 | 文本 | C-2026-001 起编 |
| 2 | 提出日期 | 日期 | |
| 3 | 来源 | 文本 | 第 N 次复盘会 / 台账A素材ID |
| 4 | 归因结论 | 文本（一句话） | 必须落到画面/文案/人群，如「开头出镜人偏老是点击率低的原因」 |
| 5 | 支撑数据 | 文本 | 具体数字，如「点击率 1.2% vs 同期 2.8%」 |
| 6 | 置信度 | 下拉：高/中/低 | 有对照数据=高；单点观察=低 |
| 7 | 验证动作 | 文本 | 下周具体做什么，可执行可验证 |
| 8 | 负责人 | 文本 | 单一责任人 |
| 9 | 验证截止日期 | 日期 | 默认下次复盘会前 |
| 10 | 验证素材ID | 文本 | 关联台账 A（素材ID），形成 A↔B 互查 |
| 11 | 验证结果 | 下拉：成立/不成立/数据不足 | |
| 12 | 后续动作 | 下拉：放大/迭代/放弃 | 成立→放大；不成立→迭代或放弃 |
| 13 | 状态 | 下拉：待验证/验证中/已闭环 | 每次复盘会开头先过此列 |
| 14 | 连续失败次数 | 数字 | ≥2 时高亮，触发南墙检讨 |

**填写红线**：① 每次复盘会段 5 新增结论 ≥1 条，但总量控制在 10 条内在途；② 「待验证」超过 2 周自动升级 FDE；③ 关闭任何一条结论必须填验证结果，不允许不了了之。

## 五、首月落地节奏

| 周次 | 动作 | 里程碑 |
|------|------|--------|
| 第 1 周 | FDE 主持首场示范复盘会；两张台账建表并回填近 2 周已测素材 | 台账 A 补录 ≥20 条历史素材 |
| 第 2 周 | 沿用五段式；FDE 退半步，只做追问和把关 | 团队能自主完成段 1~2 汇报 |
| 第 3 周 | 段 3 看片颗粒度提标（运镜/调色/BGM）；引入竞品素材对照 | 首条「验证成功→放大」闭环 |
| 第 4 周 | 指定牵头人全流程主持，FDE 列席旁听；复盘首月运行情况 | 闭环率 ≥60%，输出 v1.1 修订 |

## 六、v1.0 边界说明

- 本模板对齐《电商FDE内容闭环全链路落地SOP》阶段三「数据复盘标准化SOP（4.1/4.3）」，台账 A/B 即素材生命周期台账与优化反馈单的起步形态，待数据门户字段打通后逐步自动化。
- 暂不引入：多小组轮转制、达人素材专项对比、季节变量前置筹备表——等单 SPU 跑顺 4 周后按需加挂。
